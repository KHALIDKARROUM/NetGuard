=== CELL 0 ===
# 04 — Isolation Forest

On entraîne un **Isolation Forest** pour détecter les anomalies réseau.  
C'est un modèle non supervisé : il apprend sans utiliser les labels.  

**Principe :** les anomalies sont plus faciles à isoler dans des arbres aléatoires.  
Un point isolé en peu de coupures → score d'anomalie élevé.

**Note sur UNSW-NB15 :** les attaques sont répétitives et denses → elles ont des scores *plus élevés*  
que le trafic normal (inverse de la convention sklearn habituelle sur ce dataset).  
On gère ça en passant `contamination='auto'` à sklearn et en calculant le seuil manuellement.

=== CELL 4 ===
df_train = pd.read_csv(DATA_DIR / 'train_featured.csv')
df_test  = pd.read_csv(DATA_DIR / 'test_featured.csv')

X_train = df_train.drop(columns=[TARGET_COL]).replace([np.inf, -np.inf], np.nan).fillna(0)
y_train = df_train[TARGET_COL].values

=== CELL 5 ===
## 2. Preprocessing — QuantileTransformer

On applique un `QuantileTransformer` qui force une distribution uniforme sur chaque feature.  
C'est mieux qu'un simple scaler pour Isolation Forest : les coupures aléatoires des arbres  
sont plus équilibrées quand les features sont uniformément distribuées.

=== CELL 6 ===
qt = QuantileTransformer(n_quantiles=1000, output_distribution='uniform', random_state=RANDOM_STATE)
X_train_qt = qt.fit_transform(X_train)
X_test_qt  = qt.transform(X_test)

joblib.dump(qt, MODELS_DIR / 'qt_if.pkl')

print(f'QuantileTransformer appliqué : {X_train_qt.shape}')

=== CELL 7 ===
## 3. Fonctions utilitaires

Deux fonctions simples réutilisées dans toutes les cellules d'évaluation.

=== CELL 8 ===
def normalize_scores(scores):
    """Normalise les scores entre 0 et 1 avec min-max (NumPy vectorisé)."""
    s_min, s_max = scores.min(), scores.max()
    if s_max == s_min:
        return np.zeros_like(scores)
    return (scores - s_min) / (s_max - s_min)


def scores_to_preds(scores, contamination):
    """Convertit les scores en 0/1 selon un seuil percentile."""
    threshold = np.percentile(scores, 100 * (1 - contamination))
    return np.where(scores >= threshold, 1, 0)


# Proportion réelle d'anomalies dans le test set — utilisée comme contamination
CONTAMINATION = float(y_test.mean())
print(f'Contamination : {CONTAMINATION:.3f} ({CONTAMINATION*100:.1f}% d\'anomalies dans le test)')

=== CELL 9 ===
## 4. Entraînement de l'Isolation Forest

On passe `contamination='auto'` à sklearn pour éviter la limite à 0.5.  
Le seuil est calculé manuellement après avec `np.percentile` sur les scores bruts.

=== CELL 10 ===
print('Entraînement Isolation Forest...')
start = time.perf_counter()

if_model = IsolationForest(
    n_estimators=200,
    contamination='auto',    # seuil géré manuellement
    max_samples='auto',
    random_state=RANDOM_STATE,
    n_jobs=-1
)
if_model.fit(X_train_qt)

print(f'[timer] {time.perf_counter() - start:.2f}s')
print(f'Modèle entraîné sur {X_train_qt.shape[0]:,} connexions')

=== CELL 11 ===
## 5. Scores et prédictions

`decision_function` retourne des scores bruts sklearn.  
Sur UNSW-NB15, les anomalies ont des scores **plus élevés** (vérifié empiriquement).  
On normalise entre 0 et 1, puis on applique le seuil.

=== CELL 12 ===
# Scores bruts → normalisés → prédictions
scores_raw = if_model.decision_function(X_test_qt)
scores_if  = normalize_scores(scores_raw)
preds_if   = scores_to_preds(scores_if, CONTAMINATION)

print(f'Anomalies détectées : {preds_if.sum():,} / {len(preds_if):,} ({preds_if.mean()*100:.1f}%)')
print(f'Anomalies réelles   : {y_test.sum():,} / {len(y_test):,} ({y_test.mean()*100:.1f}%)')

## 6. Évaluation

=== CELL 15 ===
## 7. Analyse de sensibilité — effet de la contamination

On teste différentes valeurs de contamination pour trouver le seuil optimal.

=== CELL 16 ===
contamination_values = [0.40, 0.45, 0.50, 0.55, 0.60, 0.65, 0.70]
sensitivity_results  = []

print(f"{'contamination':>15} | {'Precision':>10} | {'Recall':>8} | {'F1':>8} | {'ROC-AUC':>8}")
print('-' * 60)

for c in contamination_values:
    preds_c = scores_to_preds(scores_if, c)
    f1      = f1_score(y_test, preds_c, zero_division=0)
    auc     = roc_auc_score(y_test, scores_if)
    from sklearn.metrics import precision_score, recall_score
    p = precision_score(y_test, preds_c, zero_division=0)
    r = recall_score(y_test, preds_c, zero_division=0)
    sensitivity_results.append({'contamination': c, 'precision': p, 'recall': r,
                                  'f1': f1, 'roc_auc': auc})
    print(f'{c:>15.2f} | {p:>10.4f} | {r:>8.4f} | {f1:>8.4f} | {auc:>8.4f}')

df_sens  = pd.DataFrame(sensitivity_results)
best_c   = df_sens.loc[df_sens['f1'].idxmax(), 'contamination']
print(f'\nMeilleure contamination : {best_c}')

=== CELL 17 ===
fig = go.Figure()
for metric, color in [('f1', '#2980b9'), ('roc_auc', '#e74c3c')]:
    fig.add_trace(go.Scatter(x=df_sens['contamination'], y=df_sens[metric],
                              mode='lines+markers', name=metric.upper(),
                              line=dict(color=color, width=2), marker=dict(size=8)))
fig.add_vline(x=best_c, line_dash='dash', line_color='#f39c12',
              annotation_text=f'Optimal ({best_c})')
fig.update_layout(title='Sensibilité au paramètre contamination',
                   xaxis_title='Contamination', height=400)
fig.show()
